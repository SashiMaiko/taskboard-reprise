# Accès de l’équipe

Pour accélérer l’arrivée des bénévoles, utiliser un compte GitHub commun à toute l’équipe. Son mot de passe pourra être placé dans un fichier du dépôt privé.

Donner les droits administrateur à tous les participants pour éviter les blocages.

Lorsqu’une personne quitte le projet, lui demander de ne plus utiliser le compte commun. Aucune autre action n’est nécessaire.
