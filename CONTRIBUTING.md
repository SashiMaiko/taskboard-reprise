# Contribuer

Utiliser son propre compte GitHub. Une contribution traite un besoin identifié et se prépare sur une branche dédiée depuis `main`.

Décrire dans la PR le contexte, les changements, les vérifications réellement effectuées et les limites. Demander une review à une autre personne. Les corrections sont enregistrées sur la même branche.

Une contribution est intégrable quand elle répond aux critères, que les retours nécessaires sont traités et que la validation attendue est obtenue. La personne désignée par l’enseignant effectue alors le merge.

Les fichiers et valeurs de démonstration restent fictifs. Aucun secret réel ni donnée de client réel ne doit être ajouté dans un fichier, une capture, une issue ou un commentaire. Les difficultés d’accès sont signalées à l’enseignant sans partager son mot de passe.
