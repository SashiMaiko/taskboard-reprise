# Bienvenue dans l’équipe TaskBoard

## Votre mission

Vous rejoignez un projet dont le prototype existe déjà. Une petite équipe a commencé à rédiger les documents destinés aux nouveaux arrivants. Vous devez examiner les propositions avant leur intégration.

L’histoire de l’association est fictive. Les fichiers, observations et échanges de review sont réels dans le cadre de l’exercice. Vous ne devez pas programmer : les corrections portent sur les documents.

## Contexte métier

Atelier Horizon organise des ateliers associatifs. Le prototype sert à noter les préparatifs pendant une séance de travail. La conservation entre deux visites n’a pas encore été retenue dans le périmètre.

## Informations de référence

- L’application se lance en ouvrant le fichier HTML avec tous ses fichiers voisins.
- Elle n’a ni serveur, ni authentification, ni connexion à un service externe.
- Les tâches disparaissent après rechargement.
- Aucun accès secret n’est nécessaire au lancement.
- Les comptes GitHub concernent les contributeurs, pas les utilisateurs de TaskBoard.

## Travail attendu

1. Lire l’issue liée à la PR attribuée.
2. Lire la description et les fichiers modifiés.
3. Vérifier les affirmations en utilisant le projet ou les informations de référence.
4. Formuler des commentaires précis et justifiés.
5. Soumettre une décision de review.
6. Examiner la correction et décider à nouveau.

N’inventez pas un défaut pour remplir la review. Une proposition peut être acceptable. Ne prétendez pas avoir exécuté un test si vous avez seulement lu son scénario.
